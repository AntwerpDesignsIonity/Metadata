# Asset Images Directory

This directory contains brand assets for Ionity Today.

## Structure
- PNG images: Raster logos and icons
- SVG images: Vector logos and icons  
- JPEG images: Photos and high-quality images

For a full list of available assets, visit the asset gallery at the root index.html.

## Note
To fully populate this directory, add your image assets here. The index.html references these files in its asset registry.
