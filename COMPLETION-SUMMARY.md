## 🎯 How to Deploy (3 Easy Steps!)

### Step 1: Enable GitHub Pages
1. Go to repository **Settings** → **Pages**
2. Set **Source** to `main` branch, `/` (root)
3. Click **Save**
4. Wait 1-2 minutes

### Step 2: Access Your Site
Your site will be live at:
```
https://antwerpdesignsionity.github.io/Metadata/
```

### Step 3: (Optional) Configure Custom Domain
1. Update DNS: CNAME `metadata` → `antwerpdesignsionity.github.io`
2. In GitHub Settings → Pages → Custom domain, enter `metadata.ionity.today`
3. Enable "Enforce HTTPS"
