# 🚀 Deploy This Repository Now!

## Quick Deploy (2 Minutes)

### Step 1: Enable GitHub Pages
1. Click **Settings** (top of this repository)
2. Click **Pages** (left sidebar)
3. Under "Source":
   - Branch: **main**
   - Folder: **/ (root)**
4. Click **Save**

### Step 2: Wait & Access
- Wait 1-2 minutes for deployment
- Your site will be live at:
  ```
  https://antwerpdesignsionity.github.io/Metadata/
  ```

### Step 3: (Optional) Custom Domain
1. Configure DNS: CNAME `metadata` → `antwerpdesignsionity.github.io`
2. In GitHub Pages settings, enter: `metadata.ionity.today`
3. Check "Enforce HTTPS"
